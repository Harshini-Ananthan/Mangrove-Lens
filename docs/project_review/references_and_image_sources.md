**Preferred figure workflow:** generate charts from original project metric JSON and use live, time-stamped EE imagery with full provenance. A map screenshot should include acquisition date, collection IDs, cloud/coverage quality, scale and legend. Do not use high-resolution-looking thumbnails as proof of native 10 m classification. External reference images supplied by the user are layout prompts, not evidence for the project.
