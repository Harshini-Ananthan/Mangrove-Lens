# User testing and validation: evidence versus plan

## Current evidence

The supplied reference image asks for **who was tested**, **exact task and timing**, and **an authentic quote plus resulting change**. The repository has no identified external end users, observed task trial, interview notes, consented quote or before/after design change. Code tests and live Earth Engine runs validate software execution, **not user usefulness**. Therefore the slide must say **“No external user testing completed yet.”** Do not fill the quote box with invented praise.

## Proposed first validation round

**Recruit:** 3–5 analysts across a West Bengal forest/coastal organization, a Bangladesh counterpart or domain research group, and an NGO/restoration practitioner. Recruit independently of the development team and document roles/experience; participation and access are not secured.

**Tasks:** (1) identify the acquisition month and data-quality caveat; (2) inspect an alert, satellite map, NDVI forecast and GMW reference; (3) decide whether to request field review; (4) export a report and explain its confidence to a supervisor. Use one known event, one no-event and one low-coverage case, with order randomized.

**Measures:** completion without assistance, time to reach a defensible decision, factual comprehension (month, signal, uncertainty), false positive decisions, usability ratings and willingness to repeat workflow. Record screen/notes only with consent. Ask what part of the report changed their judgment. Compare with their existing GMW/manual process where possible (Global Mangrove Alliance, *GMW 4.1 Launch*, **2026**, [source](https://www.mangrovealliance.org/news/global-mangrove-watch-4-launch)). No target speed or superiority number should appear until measured.

**Scientific validation separate from usability:** build an independent reference set from field observations or high-resolution imagery, sampling known loss, recovery, stable forest and confounders such as tides/cyclones. Blind adjudicators to Lens outputs. Report incident-level precision, recall, false alerts/month, lead time and stratification by season/country. As a comparison, use GMW alerts and simple NDVI seasonal baselines, not only a no-alert baseline. Confirm research and data-use permissions before sharing images or participant recordings.
